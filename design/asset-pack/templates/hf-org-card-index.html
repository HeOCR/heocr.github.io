HeOCR הוא פרויקט פתוח להוצאת טקסט עברי מכל מסמך: קובצי PDF ואופיס, דפי אינטרנט, סריקות וצילומים. הקוד, המודלים והנתונים פתוחים.

המודלים

  • heocr-modern-v1-tesseract-heb: מודל Tesseract לדפוס עברי מודרני.
  • heocr-oldprint-v1-tesseract-heb: מודל Tesseract לדפוס עברי ישן.

כל המודלים ב-Apache-2.0. ביצועים מדווחים רק על סטים נסתרים.

האתר: heocr.org · הקוד: GitHub · פרסומים: Zenodo · חבילת פייתון: pip install heocr

HeOCR is an open project for getting Hebrew text out of any document: PDF and Office files, web pages, scans and photos. The code, the models and the data are open.

Models

  • heocr-modern-v1-tesseract-heb: a Tesseract model for modern Hebrew print.
  • heocr-oldprint-v1-tesseract-heb: a Tesseract model for old Hebrew print.

All models are Apache-2.0. Performance is reported only on held-out sets.

Website: heocr.org/en · Code: GitHub · Publications: Zenodo · Python package: pip install heocr
