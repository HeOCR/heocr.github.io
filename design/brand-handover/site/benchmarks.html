A dash means the reader has no score on that measure. An empty cell means the measure does not apply to that document type. The last column holds a measure that exists for one type only; its name is in that type's heading row.

Each table lists the readers that handle that format. Tesseract reads images only, so it appears on scans; on PDF T6 it is scored on the image regions only.

Word error counts inserted words as well as wrong and missing ones, so it can exceed 00.0%.

Method, reference and run
  • Measure: line_fold_v1 (text normalised the same way for every reader; ratios of sums over documents)
  • Reference: D-bench synthetic sets A, B and C: generated documents with exact gold; text from the public-domain Israeli official gazette (Reshumot)
  • Licence: PD-IL (text)
  • Interval: 00.0% percentile bootstrap over documents, 2000 resamples, seed 0
  • Run: synth-2026-11-17-main; heocr at 7f5e99e
  • Reader versions: Tesseract (tessdata_best heb) tesseract 5.5, heb tessdata_best e12c65a (sha256 dbaa827a), psm 3, pages at 300 dpi gray (pdftoppm); Docling 2.150.1; MarkItDown 0.1.9 [pdf,docx]; PyMuPDF4LLM 2.1 (AGPL; benchmark baseline only, decision 0020 item 2)
  • Left out: two office-scan cases rendered with a proprietary font (their scores cannot be published), and the provisional section-number case from the label measure
  • Scoring code: HeOCR's evaluation repository (not yet public; it is published with the release gate)
