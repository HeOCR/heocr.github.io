Download HeOCR

HeOCR models are available now for modern printed documents (modern v1.0), historical unpointed print (P-hist v1.1), unpointed literary print (literature v1.0) and pointed literary print (pointed v1.0). Apache 2.0.

Which model for your document?

  • Modern printed document, unpointed: HeOCR modern MEASURED v1.0. Evaluated on the P-mod-open v0 held-out set.
  • Old book, newspaper or law, unpointed: HeOCR P-hist MEASURED v1.1. Lowest error of every reader we measured on the P-hist-open v0.1 held-out set (C2), Google’s included.
  • Literary print, unpointed: HeOCR literature MEASURED v1.0. Lowest error on the PBY-H v0 held-out set, statistically level with Rivok Tesseract.
  • Pointed (niqqud) print: HeOCR pointed MEASURED v1.0. Lowest error among the open readers we measured, statistically level with Rivok Tesseract Full, on a small set (8 works). Google’s readers are more accurate.

Quick start

The heocr Python package reads a whole document (PDF, Word files and scans) and picks the right tool for each part. It needs Python 3.11 or later, and Tesseract 5 to read scans.

Install it from PyPI, then download HeOCR’s four measured models once (about 23 MB; each is checked against its pinned SHA-256). After that, --ocr-model auto picks a model for each document and reads offline.

pip install heocr
heocr --download-model auto
heocr file.pdf --ocr-model auto -o out.txt

MEASURED or FULL?

MEASURED is the version our published held-out numbers belong to. FULL was also trained on our public test-set pages, so it has no independent score. It may be slightly stronger on similar material; this is not measured.

Advanced: use the traineddata directly

With Tesseract 5 and curl installed, save your page as page.png and run these commands in the same directory. The result is written to out.txt.

mkdir -p tessdata
curl -fL -o tessdata/phist_v2.traineddata \
  https://huggingface.co/HeOCR/heocr-p-hist-measured/resolve/v1.1/phist_v2.traineddata
tesseract page.png out -l phist_v2 --tessdata-dir ./tessdata --psm 3

The file for HeOCR P-hist MEASURED v1.1 is named phist_v2.traineddata; the release version is v1.1.
