Code signing policy

For the HeOCR desktop app for macOS and Windows.

Status

Version 0.3.0 is available from the releases page. The macOS app is signed and notarized; the Windows installer is not yet code-signed.

What is signed

Only installers built by GitHub Actions from the public source are signed, and each signing is approved by hand.

macOS: signed with an Apple Developer ID and notarized by Apple.

Windows: the installers are not code-signed yet. Once a certificate is issued, this page will name the signer and the certificate holder.

Team roles

Committers and reviewers: Shay Palachy Affek (@shaypal5), with AI coding agents that work through reviewed pull requests. Approver: Shay Palachy Affek.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The app has no network feature at all. See also the privacy policy and the full signing policy.
